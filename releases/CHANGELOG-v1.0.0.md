# Changelog — Hikayat v1.0.0

**Release Date:** 2026-07-25  
**Release Type:** Major (Genesis Release: Core RPG Engine, Discord Bot, FastAPI Web UI & Audio Engine.)  
**Package:** `hikayat-v1.0.0-clean.zip`

---

## 🌟 Most Recent Changes (v1.0.0 Highlights)

### 1. Core RPG Engine
* Built foundational Discord bot framework (`bot.py`), SQLite schema (`db.py`), LLM wrapper (`llm_client.py`), and turn resolution engine (`game_engine.py`).

### 2. Web Application Interface
* Built FastAPI server (`server.py`), single-page Web UI (`web/index.html`, `web/app.js`, `web/styles.css`), and Web Speech TTS audio engine (`web/audio.js`).

## 🏷️ Version System Specification

Hikayat adheres to [Semantic Versioning (SemVer 2.0.0)](https://semver.org/spec/v2.0.0.html):
- **MAJOR (X.0.0):** Architectural overhauls, database engine changes, incompatible configuration breaks.
- **MINOR (X.Y.0):** Substantial new features, new command suites, platform expansions, pipeline subsystems.
- **PATCH (X.Y.Z):** Backwards-compatible bug fixes, timeout protections, platform scraper adjustments, edge-case handling.
