Hikayat Custom Fonts Folder
===========================

Drop font files here to make them available in Settings -> Interface -> Fonts.

Supported formats:
  - .woff2 (recommended, smallest & fastest)
  - .woff
  - .ttf
  - .otf

Automatic family grouping (optional):
  Files named like the following merge into a single selectable family with
  working bold and italic styles:
    MyFont-Regular.ttf   (weight 400, normal)
    MyFont-Bold.ttf      (weight 700, normal)
    MyFont-Italic.ttf    (weight 400, italic)
    MyFont-BoldItalic.ttf (weight 700, italic)

After dropping or removing font files, click "Refresh" in Settings -> Interface
to reload the list immediately without restarting the server.
